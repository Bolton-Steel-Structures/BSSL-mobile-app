# iCONSTRUCTE Site — trial (demo mode)

Bolton Steel Structures' site app for operatives: check in/out, RAMS and toolbox talks, quality forms and the Works Inspection, snags and completion certificates, holidays and expenses, and issued drawings.

**This copy runs in demo mode:** sample jobs and a sample team, no real sign-in, and nothing leaves the phone. It is for trialling the screens only.

Choose a sample login on the first screen (switch later from the account menu → "Switch sample login"):
- **Liam Pilkington – Manager:** everything, plus **Manager tools** (team holidays, expenses, competency cards, time keeping and approving weeks).
- **Ian Jones – Supervisor:** everything except Manager tools (QA, all safety and quality forms).
- **Daniel Wiseman – Operative:** drawings, sign RAMS, check in / out, holidays, expenses, My cards, near miss and NCR only.

What each role sees is set in `config.js` (`roles`).

Open on a phone, then add it to the home screen:
- iPhone: Safari → Share → Add to Home Screen
- Android: Chrome → menu → Install app

The real version (with Microsoft 365 sign-in and the office link) is maintained in the private iCONSTRUCTE repository.
