# iCONSTRUCTE Site — trial (demo mode)

Bolton Steel Structures' site app for operatives: check in/out, RAMS and toolbox talks, quality forms and the Works Inspection, snags and completion certificates, holidays and expenses, and issued drawings.

**This copy runs in demo mode:** sample jobs and a sample team, no sign-in, and nothing leaves the phone. It is for trialling the screens only.

Open on a phone, then add it to the home screen:
- iPhone: Safari → Share → Add to Home Screen
- Android: Chrome → menu → Install app

The real version (with Microsoft 365 sign-in and the office link) is maintained in the private iCONSTRUCTE repository.
